# Conversational loot-editing style

Use this structure when the user wants casual commentary plus gameplay actions rather than a pure highlight reel.

## Selection order

1. Keep container and safe searches, room-card use, ability activation, high-value loot, combat consequences, and extraction outcomes.
2. Keep the spoken setup before an event and the reaction after it. Extend to the nearest natural pause; never cut a sentence only to hit a fixed duration.
3. Keep short route bridges only when they establish the next location, explain a decision, contain useful commentary, or build danger.
4. Remove repeated empty searches, silent straight-line running, duplicate inventory sorting, loading, menus, and waiting unless they support a joke or story beat.

## Rhythm

- Open with an active gameplay image and one clear conversational premise.
- Reach the first search, card, ability, danger, or result beat within 10 seconds when the source permits.
- Alternate talk/setup → gameplay action → result/reaction. Avoid stacking many context-free UI clips.
- Hold a readable loot or inventory result for 2–4 seconds when it changes the story.
- Preserve continuous combat audio and spatial continuity; avoid decorative inserts during a fight unless the user asks for them.
- Show accumulated stakes before extraction. Keep failure when it completes the story.

## Review boundary

Visual detection can propose clips, but a human must judge sentence completeness, joke timing, whether a route segment is informative, card/ability semantics, and whether a repeated search is truly redundant. Do not imitate another creator's voice, catchphrases, nickname, identity, or signature graphics.
